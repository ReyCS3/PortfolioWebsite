Beach Circle

A comprehensive web and mobile campus platform for CSULB.

My Role

Full-Stack Developer

Tech Stack

Flutter, Firebase, Dart

The Team

Josue Alfaro-Garcia, Giselle Hernandez, Theresa Nguyen, Tiffany Nguyen

The Vision

Developing a unified platform to connect students, streamline campus interactions, and foster a stronger digital community. Beach Circle bridges the gap between web and mobile users through a seamless, responsive architecture.

Secure Authentication & User Profiles

I engineered the foundational identity system, ensuring secure and frictionless access for all campus users. By integrating Firebase Authentication, I created a robust system that handles secure logins, session management, and dynamic user profile data generation.

  • Implemented secure credential handling and session persistence.
  • Designed the Flutter UI for onboarding and profile management.
  • Structured NoSQL databases to efficiently link user profiles to app activity.

Real-Time Parking Difficulty Indicator

To solve one of the biggest pain points for commuters, I developed a dynamic parking indicator. This feature translates raw data into an intuitive, color-coded UI component within the Flutter app, giving students immediate insight into lot availability.

  • Built real-time database listeners to push updates instantly to the client.
  • Designed responsive, visual state indicators (e.g., Red/Yellow/Green capacity).
  • Optimized data fetching to minimize load times and reduce backend reads.

Community Content Moderation System

To maintain a safe and productive campus environment, I architected a comprehensive moderation pipeline. This system empowers administrators to efficiently review, flag, and manage user-generated content across the platform.

  • Developed administrative privileges and role-based access control.
  • Created secure backend logic for flagging and hiding inappropriate content.
  • Built an administrative dashboard UI for quick content review and action.
